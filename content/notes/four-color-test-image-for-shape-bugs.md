一个手机 App 里，头像在安卓上看起来是方的，像是圆角没生效。先后换了四种写法：图片自带圆角、外层裁切、SVG 裁切、四个角分别写半径，看起来都没用，还为此开了一张问题单。

## 原因

其实没有 bug。测试用的头像是一张截图，左上角本来就是一大块白色，和浅色背景混在一起。看到的那条“直角边”，是截图里某个白色按钮的边，不是头像的边。

换成一张四个角颜色各不相同的纯色图，大小两种头像在安卓模拟器上都是完整的圆。之前那几种写法里，早就有生效的。

截图和照片边上常有大片浅色或纯色，很容易让人看错形状。

## 怎么做

查圆角、裁切、遮罩、边框这类问题时，用四个角颜色分明的纯色图来测，不用截图或照片。

看之前先想一下：我看到的这条边，是容器的边，还是图片里本来就有的边？

生成测试图只要几行 Python（需要装 Pillow）：

```python
from PIL import Image

size = 512
half = size // 2
image = Image.new("RGB", (size, size))
colors = [(230, 40, 40), (40, 160, 60), (40, 80, 230), (240, 200, 20)]
boxes = [(0, 0, half, half), (half, 0, size, half), (0, half, half, size), (half, half, size, size)]
for color, box in zip(colors, boxes):
    image.paste(color, box)
image.save("four-color-test.png")
```

安卓模拟器里，用 `adb push` 把图片放进相册目录，再触发一次媒体扫描，就能在相册里选到。

查到最后发现“其实没坏”，也算查清楚了，把原因写进问题单再关掉。

## 适用情况

网页和手机 App 里跟圆角、裁切、蒙版、头像、边框、阴影边缘有关的问题都适用。如果是尺寸算错之类和颜色无关的问题，这个办法帮不上忙。
