一个手机 App 里，头像在安卓上看起来是方的，圆角好像没生效。先后试了四种写法：图片自带圆角、外层容器裁切、SVG 裁切、显式写四个角的半径，看上去全都“不生效”，还为此开了问题单。

## 原因

**事实**：根本没有 bug。测试用的头像是一张截图，左上角本来就是一大块白色，和浅色页面背景融在一起。看到的“直角边”其实是截图内容里某个白色控件的直边，而不是头像容器的边界。

换成四个象限颜色各不相同的纯色测试图后，大小两种尺寸的头像在安卓模拟器上都是完整的圆，原来那几种写法里早就有生效的。

**推断**：截图和照片的边缘经常有大块浅色或纯色区域，天然会骗过肉眼对“形状”的判断。

## 怎么做

- 查圆角、裁切、遮罩、头像边框这类形状问题时，测试素材一律用“四个角颜色分明”的纯色块图（四个象限用四种高对比色），不用截图或照片。
- 这种图可以用脚本几行生成。安卓模拟器可以用 `adb push` 把图片推到相册目录，再触发一次媒体扫描，就能在系统相册里选到。
- 判断之前先问自己：我看到的这条边，是容器的边，还是图片内容自己的边？
- “查到底”也包括查出“其实没坏”，然后把原因写清楚再关单。

下面是用 Python（需要安装 Pillow）生成测试图的示例：

```python
from PIL import Image

size = 512
half = size // 2
image = Image.new("RGB", (size, size))
colors = [(230, 40, 40), (40, 160, 60), (40, 80, 230), (240, 200, 20)]
boxes = [(0, 0, half, half), (half, 0, size, half), (0, half, half, size), (half, half, size, size)]
for color, box in zip(colors, boxes):
    image.paste(color, box)
image.save("four-color-test.png")
```

## 适用范围与失效条件

适用于网页和移动端里涉及圆角、裁切、蒙版、头像、图片边框、阴影边缘的视觉排查。

如果问题本身和颜色无关，比如布局尺寸算错，这个方法帮助有限。
