title: React Native 安卓上调大系统字号，文字被截掉、行距乱跳
summary: 字号上限只管字号，不管行高和字距。三者按同一个倍数一起放大就好了。
publishedAt: 2026-10-11

---

一个 React Native 手机 App，给文字设了最多放大 1.15 倍的上限。把安卓系统字号调到 2.0 之后：字只大了一点，行距却忽大忽小，文字上下被切掉一半，带阴影的大数字底下露出一串像省略号的残影，多行大标题叠在一起。同样的设置在 iPhone 上没问题。

## 原因

在安卓模拟器（Android 15）上一页页截图对比，找到了原因：

- 当时用的 React Native 0.86，安卓上的 `maxFontSizeMultiplier` 只限制字号。行高（`lineHeight`）和字距（`letterSpacing`）还是跟着系统字号放大，不受这个上限管。
- 从 Android 14 开始，系统字号的放大不是等比例的：字越大，放大得越少。
- 两件事叠在一起：13 号字只放大了 15%，20 的行高却被放大到 34 左右。字和行的高度对不上，于是被截掉、错位、留残影。

还走过两条弯路：

- 想把行高和字距按系统倍数先除回去。因为放大不是等比例的，除不准，反而让两行标题叠在了一起。
- 让每个文字组件都监听屏幕尺寸变化。App 运行时改系统字号会直接崩溃。

## 怎么做

- 做一个统一的文字组件。安卓系统字号大于 1 时，关掉原生的字号缩放（`allowFontScaling={false}`），自己用 `k = min(系统字号倍数, 上限)` 把字号、行高、字距三个一起放大。文字套文字时，里面那层不要再放大一次。
- 每次渲染时直接读当前系统字号，不要让每个文字组件都去监听屏幕尺寸。
- 屏幕很窄（宽度大约不到 360）时，倍数退回 1，免得挤到截字。
- 内嵌网页（WebView）加 `textZoom={100}`，免得安卓只放大网页里的字，原生按钮却没变。
- 给这几条加上测试：等比例放大、嵌套不重复放大、窄屏退回、文字组件不监听屏幕尺寸。

改完之后，安卓在大字号下和 iPhone 一样按比例放大，三十多张截图里没有再出现截字和重叠。

## 适用情况

适合在安卓上设了字号上限、或者依赖系统字号的 React Native App。其他框架如果也是只限字号、不限行高，可以按同样思路查一下。

以后如果 React Native 让行高和字距也遵守上限，或者安卓改回等比例放大，就可以换回原生缩放。窄屏退回这一条对 iOS 的影响，还没在 iOS 模拟器上测过。
